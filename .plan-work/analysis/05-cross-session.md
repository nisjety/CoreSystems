### 5.0.2 Id prefixes used in this section

`WSnn` = Space workstream (this plan). `mp-WSnn` = sibling (b) workstream. `qb-WSn.x` = sibling (a) workstream and slice. `F-t1/F-t2/F-t3-nnn` = audit items. `DEC-nn` = (b) decisions. `ADR-n`, `X-n`, `R-n` = (a) decisions and reconciliations. `SP-ADR-n` = the Space audit's ADR 1-10 (renamed so they cannot be confused with (a)'s `ADR-1..10`). `C1-C23`, `O1-O11` = cross-audit overlap ids. `N1-N15` = new conflicts found in this pass. `X01-X36` = rows of the shared-piece table.

### 5.0.3 Rules applied to every ruling

Control owns authority (decisions, grants, audit, entitlements); Model proposes and Quarry executes; Data owns knowledge; no cross-plane DB; ZDR propagates; a Space only narrows an owner-plane decision (master matrix rule 10). "Consume, not rebuild": where a sibling has built or reserved a piece, Space takes its names and numbers.
