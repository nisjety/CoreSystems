### F-t2-005 · One strict ScrapeOptions contract: formats[], inline return (the ZDR path) and main-content controls
| Tier | Verevon today | Effort | Plane | Wave | Confidence |
|---|---|---|---|---|---|
| Priority | Partial | M | Ingestion Plane (quarry-core, quarry-transform, quarry-edge); thin clients elsewhere | W1 | High |

**What to build.** Define ScrapeOptions once in quarry-core and scope the first slice to `POST /v1/scrape`: `formats[]` with inline markdown, html, links and metadata under a size cap with FormatRef fallback; `onlyMainContent` and include/exclude selectors via a clean_html stage ahead of readability; a selectable raw or clean_full extractor; `effectiveOptions` and a scrape_id in the response; `GET /v1/scrape/:id` for non-ZDR runs. Switch model-gateway web_fetch to the inline path. Embedding in crawl, batch, search hydration and schedules is a follow-on.

**Why it matters.** Every agent web_fetch pays two calls (scrape, then artifact GET), and a ZDR scrape returns no text because outputs exist only as artifact refs never written under ZDR. Inline return is the natural ZDR path. One validated contract lets the Model propose options and Quarry reject bad ones with field-level 400s.

**What the references do.** Inline scrape is 2 of 4 references (Firecrawl, Apify), table stakes for a scrape API; a shared strict options contract and scrape-by-id are each 1 of 4 (Firecrawl). Firecrawl validates every request against one zod strictObject, takes a per-team concurrency permit with a bounded wait (two thirds of the timeout), runs the pipeline in-process and returns one Document with per-format fields and metadata; `waitFor` is capped at half the timeout [SRC]. Every transformer runs and checks its own option, redaction runs early, and a final coercion strips unrequested fields [SRC]. The job-access row is written even for ZDR requests; `GET /scrape/:id` is refused only for teams forced into ZDR, so writing nothing under ZDR is a Verevon choice [SRC]. Its native cleaner removes 42 chrome selectors unless a node holds one of 13 force-include regions [SRC]. The extractor choice with fallback comes from Apify's Website Content Crawler and keys on whether the page is a clear article [DOC]; Apify Web Fetch offers only markdown, html, text, links and raw with a 10 MB cap [DOC]. Caveats: Firecrawl silently defaults `skipTlsVerification` to true unless headers or actions are set, never copy that; its openapi.json lags the code.

**Verevon today.** ScrapeRequest takes url, prev_fingerprint, cache (with max_age_s), zdr, privacy, signals, ingest, org_id, render hints and prefer_http3 (apps/Ingestion Plane/Quarry-v2/crates/quarry-edge/src/routes.rs:345-375): no formats, timeout, selectors or deny_unknown_fields, so the gateway's formats and maxPages keys (gateway search.rs:112-140) are silently ignored. Only POST is routed (routes.rs:131). Output is FormatRef only (quarry-core/src/output.rs:129-150); under ZDR html and markdown become None (quarry-runtime/src/pipeline.rs:597-690), and model-gateway makes a second artifact call (model-gateway/src/quarry.rs:755-775). One readability pass runs (pipeline.rs:506) with a whole-HTML fallback only on failure (readability.rs:235-240). docs/OSS_PARITY_BACKLOG.md:18-34 claims parity; the code contradicts it. Reuse readability.rs, links.rs, metadata.rs, images.rs, attributes.rs, CachePolicy.max_age_s and `zdr::guard` with WriteKind.

**How to build it in Verevon.** Ingestion Plane owns the contract. ZDR: inline return writes no artifacts and no cache, no scrape-by-id for ZDR, and any URL-plus-options cache is org-keyed and bypassed under ZDR. Keep a lenient unknown-field period because gateway callers already send extra keys. Adopting schemars is a new dependency decision; openapi.yaml is hand-maintained; verification moved the OpenAPI-generation slice with a CI route-coverage check from [F-t2-064](#F-t2-064) into this item. Crawl and batch are refused under ZDR and handed to the Go orchestrator, so embedding there is L. Risks: large payloads, selector lists deleting real content (golden-page fixtures), and output changes shifting monitor fingerprints.

**Quick win.** The scrape-only slice reuses existing transformers and removes a round trip from every agent fetch.
