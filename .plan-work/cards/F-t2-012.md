### F-t2-012 · Chat beside the browser: a dockable browser panel bound to the chat run
| Tier | Verevon today | Effort | Plane | Wave | Confidence |
|---|---|---|---|---|---|
| Priority | Partial | L | Frontend Plane | W2 | High |

**What to build.** Two slices. (a) Frontend (M): give the existing chat live-run panel dock positions (right, bottom, maximised, hidden) persisted per user, a floating composer over the page, and a "new chat per tab or keep the chat" rule. (b) Backend (L): bind the panel to a live, steerable session, either through a gateway projection of execution-core-owned Quarry runs (owner-gated, exposing Quarry's frame stream and control routes) or by letting a chat turn act on a user-created session, plus real BrowserBroker grant issuance for UI-driven runs.

**Why it matters.** Both reference browsers converge on chat and page side by side: the user watches, takes over and asks about the visible page in one view. Verevon has the pieces but the chat view is read-only and shows the agent's separate page.

**What the references do.** Present in 2 of 4 references (Codex, Aside); table-stakes for a chat-plus-browser product. Codex hosts the browser pane with destinations new-window, left, right, bottom, pin, chat and new-chat, plus a hidden browser-use host; commands toggle the panel and step through workspace layouts, and a floating composer is revealed when the pointer nears the bottom of the page, with a thread-scoped option to hide it [SRC]. That the composer posts into the active chat is inferred; the send path was not traced [INF]. Aside runs a per-tab side panel: `sidePanel.setOptions` per tab with a session id, session resolution when a tab activates, a new-session or keep-session setting (default new-session), and a "sidecar to this page" framing block injected on the first user message for the first attached tab [SRC]. Caveats: the Codex pane sits behind a server-delivered gate that defaults to false [SRC]; Aside is a local single-user browser [SRC].

**Verevon today.** A right-docked, collapsible chat split exists: ChatPage mounts `ChatLiveRunPanel` (apps/Frontend Plane/verevonv3/src/features/chat/components/ChatPage.tsx:957-984), which reuses `BrowserChrome` in compact mode (ChatLiveRunPanel.tsx:608) with pause and resume. It is read-only, fed by per-step artifact screenshots, and only for planned and deep-research turns: `browserSessionFromChatRun` leaves every live-frame URL null and the session id undefined, so manual controls stay disabled (apps/Frontend Plane/verevonv3/src/features/chat/lib/chat-run-watch.ts:402-452). The interactive BrowserChrome with takeover, approvals and frame streaming is mounted only in the Crawl composer (KnowledgeScrapePreview.tsx:253). There is no dock position, floating composer or new-chat rule, only a collapsed flag (chat-run-watch.ts:45). Reuse the panel and its compact mount, the chat-run-watch adapter, the gateway frame, control, timeline and artifact routes (apps/Frontend Plane/verevonv3/apps/gateway/src/domains/browser.rs:371-444), the `owned_orchestration_run` ownership proof (browser.rs:3310-3347) and the ChatWorkspaceCanvas layout as dock host.

**How to build it in Verevon.** The Frontend Plane owns presentation only; page context reaches the Model Plane only through governed `browser.observe` results or attachments, never raw DOM from the SPA. A chat turn's browser runs inside execution-core with its own Quarry lease and grant (browser.rs:3320-3345), while the dashboard's `start_ai_run` acquires a separate lease and only re-navigates to the tab's URL (browser.rs:1237, 1311-1318), so the user's page and the agent's page differ today; closing that is the L part. Takeover goes through the gateway control route and Quarry control mode, which depends on [F-t2-013](#F-t2-013); UI-driven runs still use an interim `session:{id}` grant id (browser.rs:1258-1262), so [F-t2-001](#F-t2-001) is a prerequisite. ZDR chat runs have no frames: do not persist dock state server-side and keep the panel's honest ZDR copy. Risks: small-screen layout and frame bandwidth beside streaming chat.
