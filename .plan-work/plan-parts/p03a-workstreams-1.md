## 3. Workstreams

Each block condenses one design (`.plan-work/design/WSnn.md`) into items resolved, owner planes, the slice table in build order, key files, contract and migration changes, flags, test commands, definition of done, effort and risks; engineer-weeks are for one engineer who knows the plane, and "WS03" in this plan always means the Space governance workstream, never the Model Plane durable-loop slices of the same name. File states are as at design time on the live main tree (COMMITTED, M = modified-uncommitted, U = untracked, NEW = added by the slice), and the local `model-plane` branch has since committed part of the M/U Model Plane and SPA ZDR set (for example session-core migrations 0044 to 0048 and the typed ZDR refusal files), so slices that need them build on a tree merged with that branch. Migration numbers marked "design" were reserved by the designs and several collide with each other or with the Model Plane build and plan, so every final number comes from one allocation table assigned at merge (see the numbering notes under WS01 and WS03).
