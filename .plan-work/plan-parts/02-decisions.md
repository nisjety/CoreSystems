## 2.0 Vocabulary

- **DEC-nn**: global decision id used by every workstream section of this plan. WSnn Dn / Qn = the local id in the design (map in 2.3).
- **Decider** codes: OWN = owner ruling (the product/system owner; recorded in the owner-rulings file `apps/Frontend Plane/verevonv3/apps/verevon-web/plans/system-audits/program-2026-10-03/owner-rulings-and-defaults.md`, or as a dated ledger/ADR entry); MPO = Model Plane owner/integrator; CP = Control Plane team; APP = Application Plane team; PROD = product; CNS = counsel; OPS = operator/release; SPACE / QRY = sibling Verevon Space / Quarry-browser session.
- **OD / D10 / F12** are labels from `CHAT_GAP_CLOSURE_PLAN_2026-10-01.md` section 7 (OD1-OD20 at L417-L512). Each has a recommended default but, except where noted, no recorded ruling. Namespace caution: `program-2026-10-03/build-manifest.md` reuses OD4/OD7/OD8/OD10/OD11 for other questions; read OD numbers against the chat-gap plan only. CHATGAP L195 cites "OD5" for D10 go/no-go but D10 is OD9 (L457-459).
- **Owner rulings in force** (do not re-open): 2026-09-28 "scheduled runs are draft-only, personal connections are owner-only, Chrome control means the hosted governed browser, mail-to-task is Postmark self-forward" (CHATGAP L68; NOT in the ledger); 2026-10-03 rulings 1-6 and defaults D-A..D-E (ZDR switch gated on attested provider; waived runs skip memory indexing/dreaming/learning review; background budget alert-only); rule R17 "no admin lock". Ownership rules R1-R18 of `apps/master-ownership-matrix.md` section 3 bind every DEC (R9/R10 membership, R12 provider-write receipts, R17 waiver, R18 service-principal allowlist).
- **Ledger** = `apps/Model Plane/docs/decisions/ledger.md`. States: proposed, implemented, deferred, rejected, archived. Supersede with a new entry, never rewrite. "Blocks building?" means blocks starting/merging code, not enabling a flag.
