## 1. Goal, success criteria and scope

### 1.1 Goal

One web interface in which a user chats, writes and runs code, produces and edits files and images, researches with citations, and delegates multi-step work to an agent that uses a sandbox computer and a governed browser, at the capability level of manus.im, perplexity.ai, chatgpt.com and claude.ai. The differentiator is kept, not traded: tenant isolation, signed fail-closed tool authority, Zero Data Retention (ZDR) by construction, and honest outcomes (audit section 8: "protect it"). Everything lives in Model Plane plus the chat and agent pages of Verevon v3, with only the Control, Application, Ingestion and Data slices the workstreams name.

Method: Wave 1 (WS01-WS12) makes what exists trustworthy and provable; Wave 2 (WS13-WS27) closes the agent-loop and governance gaps. "Done" means the repo evidence rule of section 6.2: rebuilt images, a running stack and a verified end-to-end flow, never source plus a unit test alone.
