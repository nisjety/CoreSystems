## Surprises

1. The audit (verdict exactGap) says no thread-appended event exists to project. Session Core already writes a MESSAGE_APPENDED row to events in the same transaction as each message (grpc.rs:2604-2621), plus THREAD_CREATED (580-628), THREAD_PRESENTATION_UPDATED (5735) and THREAD_ARCHIVED (5895). The gap is the publish path, not the existence of the event.
2. Adding a thread or space subject family needs four changes the card does not name: classify_outbox_subject (audit_publisher.rs:69-83), a new migration after 0045 to replace the subject CHECK (0016:26-34), a session-core-runtime publish grant (nats.conf:38-53), and a Convex case in http.ts (111-121).
3. The sequence source is weaker than the card implies. events has no per-Space or per-thread ordinal (0002 ordinals cover only STEP_COMPLETED per run). messages.sequence is a table-global identity (0001:19). The run replay buffer is best-effort (orchestration_grpc.rs:195-215, Redis fire-and-forget) and the live tail is a process-local broadcast (337). A resumable, sequenced stream needs a new durable sequence.
4. The gateway has no Model Plane NATS identity, URL or compose variable (config.rs; verevonv3 docker-compose.yml:154-164 covers only GDPR). A NATS-fed Space stream needs a new principal in deploy/nats.conf, compose env and provisioning.
5. Erasure (grpc.rs delete_thread_rows, 362-396) purges session_audit_outbox by payload thread_id and run_id. Its third predicate matches payload->>'subject' against run ids, which can never match a NATS subject. Outbox payloads for thread or space events must carry thread_id.
6. Two brokers are in play. Run events and the Convex mirror use model-nats (nats-subscriber.js:262-290; Application compose 253). Membership and GDPR use control-shared-nats (session-core main.rs:109, 135-142; compose 731). The design must pick one per subject family.
7. Uncommitted work overlaps the outbox and migration numbering: retention_receipt.rs (UNCOMMITTED-NEW) inserts into session_audit_outbox (489); migrations 0044 and 0045 and revert/ are untracked. Any WS02 migration must land after 0045 once that work is committed.
8. SPACE_PAGE_AUDIT_2026-09-06.md (98, 387) says a durable "R-4" delivery projection is "already built at source". The only Convex outboxes are lifecycle and audience (schema.ts:680-713, 873-892); neither carries thread or message events. R-4 has no definition in that doc.
