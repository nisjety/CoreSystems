4. The verdict's session_flow.rs:2025-2075 evidence is test code inside `#[cfg(test)] mod tests` (starts 1652). The production durable-write gate is grpc_auth.rs:320-345.

6. No resource caps exist. No rlimit, prlimit, cgroup, pids, cpu, memory or ulimit setting appears in execution-core/src, sandbox-manager, or deploy/. sandbox-manager `Limits` (store.go:264-290) count processes and bytes only.

10. The verdict says Control and the gateway make the Space ZDR flag unreachable. Control's `ValidateForAgentAction` refuses ZDR at personal_thread_decision.go:292 (verified). The gateway spaces.rs has no ZDR references (verified by grep). The flag is still decoded at grpc.rs:1754 and discarded.
