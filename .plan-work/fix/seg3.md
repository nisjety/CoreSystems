**Plane ownership / ZDR / Model-proposes-Quarry-executes check:**
- Frontend Plane owns the omnibox, dock, strip, panels and the same-origin gateway normalisation (typed envelopes, no upstream secrets, no raw OAuth tokens, no forged scoping headers; the gateway derives org and user from `require_session` and `resolve_browser_run_owner`, never `x-verevon-org-id`, enforced by the fabrication guard); nothing is persisted in the Data Plane; omnibox history and dock state are local storage; receipts and procedures are read from Quarry over HTTP with the user's owner-scoped token; no cross-plane database access (the "admit org members to service-owned runs" variant is rejected).
- ZDR: no omnibox history, suggestions or search-home recording under ZDR (client and gateway); dock state is layout only and never server-side; evidence panels are unavailable under ZDR except the live-only egress read and nothing from panels is persisted in the SPA; free-text search under ZDR goes through the WS4-fixed gateway path (no cache, no `SearchIssued`); a ZDR thread's dock is a human-only browser (model-gateway already refuses ZDR browser runs).
- Every human action (navigate, reload, click, take over) is a request Quarry validates against the grant and domain list; `reload` is human-only and absent from the Model tool schemas; `browser.console` is read-only and grant-checked; page context never travels from the SPA to the Model (the Ask paths attach nothing).
