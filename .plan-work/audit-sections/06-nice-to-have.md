## 6. Nice to have

Nice-to-have items are improvements that none of the priority or recommended work depends on. Some are polish that the reference browsers ship and users will eventually expect; others are bets that the code verification demoted from "recommended" because a premise did not hold, a prerequisite is unbuilt, or an owner ruling parks them. Status, effort and approach on every entry come from the verified data for Verevon at commit afb83928 (2026-10-10); where a note says "demoted", the verification pass changed the tier. Acronyms used below: ZDR is Zero-Data-Retention, UA is user agent, CDP is the Chrome DevTools Protocol, MCP is the Model Context Protocol, ADR is an Architecture Decision Record, SIEM is Security Information and Event Management.
