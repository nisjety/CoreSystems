**API, proto, data model and migrations**
- No migration number is consumed (user-core stays at 029 for WS16; WS03/WS04/WS09/WS10/WS12 hold 033+). No proto, no Control decision type, no NATS subject, no Channel Plane work.
- Control preference contract v2 (additive, storage stays `user_settings` categories `language` and `appearance`): `GET /api/v1/preferences` returns `{"preferences":{theme, language ("en-US" default kept), timezone (omitted unless a valid IANA zone, legacy `region` read only if valid, never `"US"`), dateFormat (`MM/DD/YYYY|DD/MM/YYYY|YYYY-MM-DD`), timeFormat (`12h|24h`), compactMode, crawlIngestMode, notifications, explicit:{language,timezone,dateFormat,timeFormat,compactMode}}}`; stored `auto` is not explicit. `PATCH` accepts the same plus `auto`, validates `timezone` with `time.LoadLocation` (400 `{"error":"timezone must be an IANA zone name"}`) and `language` against `^[a-z]{2,3}(-[A-Z]{2})?$` (max 10); writes key `timezone`, stops writing `region`. Errors stay legacy plain strings until WS03 moves user-core to the typed envelope.
- Locale precedence (SPA): first paint from `localStorage`; adopt-once (marker `verevon.locale.synced.v1`: local value wins and is PATCHed); then server wins when `explicit.language` maps (`nb*/nn*/no*` -> `no`, `en*` -> `en`, else untouched); user toggle writes through (debounced 500 ms, `verevon.locale.dirty=1` on failure, dirty local wins next boot).
- Sidebar document `SidebarDoc` v1 (<= 32 KiB; refs only: `starred` <= 100, `hidden` <= 500, `sections` <= 30 with <= 200 refs each, section name NFC 1-40 chars unique case-insensitively, `groups` closed ids `channels|dms|personal|archived`, `computed {needsYou, unread, working, muted}`; ref charset `^[A-Za-z0-9_.:-]{1,128}$`). Convex table `spaceSidebarPreferences` (`externalOrgId`, `externalAuthId`, `revision`, `doc`, `createdAt`, `updatedAt`; index `by_subject`); functions `spaceSidebar:getForGateway`, `spaceSidebar:putForGateway {baseRevision, doc}` -> `{status:"ok", revision}` or `{status:"conflict", revision, doc}` (each starts `assertServiceKey` then `requireGatewayMember`), `spaceSidebar:sweepOrphans` (S11).
- `GET /api/v1/spaces/sidebar` -> `200 {"data":{"mode":"server","revision":3,"doc":{...}|null,"limits":{"sections":30,"refs_per_section":200,"starred":100,"hidden":500,"name":40}}}`; under org ZDR `{"mode":"zdr_local","revision":0,"doc":null,...}`; errors 404 `space_sidebar_disabled`, 403 `active_membership_required`, 503 `space_sidebar_unavailable`. `PUT /api/v1/spaces/sidebar {"base_revision":3,"doc":{...}}` -> `200 {"data":{"revision":4,"doc":{...}}}`; errors 400 `invalid_sidebar_doc` (`details.reason`), 409 `space_sidebar_conflict` (`details:{revision, doc}`), 412 `zdr_durable_mutation_forbidden`, 413, 404, 403, 503.
