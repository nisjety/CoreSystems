## 2. Per slice group: what is implemented, completeness, tests, switch, gaps

### 2.1 S3 corrections (stage-1 hardening) - COMPLETE against reconcile unit 1 (a)-(g); S7/S9 consumers not built

Implemented:
- Waived and ZDR runs never get a loop approval; a Space run or a pinned-route run also gets a cold approval (a `/continue` states neither Space nor route and would be refused after the single-use consume). Non-releasable tools (`browser_agent`, `book_shipment`, `subagent.*`, ticket tool) get cold mode.
- `/continue` and `ConsumeApproval` refuse non-persistent turns (gateway early gate with the same `not_resumable` a finished run gets) and non-persistent or ended runs (store SQL).
- Every consumed approval is refused at the gateway (409 `continuation_already_consumed`); the executor additionally refuses a same-claim replay unless the effect ledger is on (it fences the second dispatch).
- A continuation runs under the authority its pause retained: `effective_authority` narrows only, refuses widening with closed tokens `authority_widened`, `authority_space_mismatch`, `authority_route_mismatch`; `apply_authority` writes it onto the request before the loop reads it.
- Segment number is derived by the executor from the paused step id (`s{n}.` prefix), gateway sends 0, so two continuations of one run no longer share step ids.
- `Authority::narrows` fixed: unspecified/unknown rung is widest, permission mode is ranked (deny < ask < auto, unknown widest).
