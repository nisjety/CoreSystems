## Traps and findings
1. NewTabBody (crates/quarry-edge/src/agent_routes/types.rs) is `rename_all = camelCase` with alias `initiatedBy`: a body with snake_case `initiated_by` is accepted and ignored (no deny_unknown_fields), so the tighten-only hint is lost and an agent call opens a tab during a take-over. Select/close read the hint from the query with both spellings; `/step` takes `initiated_by`. Fix: add alias `initiated_by` to NewTabBody.initiated_by (and a test). Not fixed here (evidence unit).
2. The tabs routes are not in docs/openapi.yaml at all.
3. R7's RUNBOOKS text says the bomb is answered '415 pdf_parse_failed with details.reason too_large'; the wire shows reason too_large only (code UNSUPPORTED_MEDIA, details {kind: pdf, reason: too_large}), as docs/ERROR_REASONS.md lists it.
4. Check 5 'OFF' run: person select of tab-2 returned 502 chromiumoxide tab not found because the agent had closed tab-2 in step C (enforcement off lets it); a script artefact, not a defect.
5. Default QUARRY_CHALLENGE_ENFORCE=log: the interstitial scrapes 200 with its text; the 403 needs enforce.
