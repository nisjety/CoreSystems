## Assumed decisions

- Contract shape proposed by Quarry (POST with the URL in the body, base64 body in a `{data}` envelope, typed 404 miss), because no Data Plane contract exists; the plan says "reads Data Plane artifacts only via its API and returns a typed miss without logging the URL".
- The typed miss is `NOT_FOUND` with `details.reason = no_egress_miss` (no new `ErrorCode`, R-10 style, like the E3.8.1 sub-codes).
- ZDR is refused (`FORBIDDEN`), not served: stored artifacts are durable content and ADR topic 4 refuses URL-keyed reads for ZDR runs. `ZdrEphemeral` classification counts as ZDR.
- No fallback to live egress on a miss: that is the point of the mode.
- A missing route (bare 404) is not a miss, so a misdeployed Data Plane cannot pass for "nothing stored".
- The served-by kind is `Static` until quarry-core has a stored-read variant.
- The reader takes its manifest row from the caller instead of calling `from_manifest` with a row that does not exist (which would break the manifest contract test).
