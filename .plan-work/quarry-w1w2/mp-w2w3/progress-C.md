## MP-3 contract (model-gateway, lane B builds it; what the broker will expect)

- Routes: `POST /v1/browser/key-grants`, `DELETE /v1/browser/key-grants/:grant_id`. Accept ONLY an api_key principal (`PrincipalKind::ApiKey`), refuse user and service (403); api_key refused on every other route. Ingress needs CP-1 audience `model-gateway` (ask below); the delegated bearer to the broker is the `aud=browser-broker` key token with the same `sub`, `org_id`, `key_id`, `zdr`.
- POST body: `{ allowed_domains: string[] (required, 1-32), budget: { micro_usd: int64 > 0, max_steps: int32 > 0, max_runtime_s: int32 > 0 } (required, all three), zdr?: bool, ttl_s?: int (only shortens; broker clamps) , session_key?: string }`. No `kind`, no `read_only`, no sensitive fields, no renew route. The door maps to `AcquireGrant{org_id from token, session_key (door-generated if absent), mode "cloud", allowed_domains, budget_* , budget_source "request", zdr, ttl_seconds}` with `grant_kind` empty.
- Response 201 `{ data: { grant_id, expires_at, allowed_domains? (omitted when zdr), budget: {micro_usd, max_steps, max_runtime_s}, key_id } }`.
- Broker codes -> HTTP (typed `{error:{code,message,details:{reason}}}`): PermissionDenied with switch off -> 403 `api_key_grants_disabled`; PermissionDenied host outside ceiling -> 403 `api_key_host_ceiling`; PermissionDenied budget over ceiling -> 403 `api_key_budget_ceiling`; InvalidArgument (budget missing, hosts invalid) -> 400 `invalid_request`; ResourceExhausted -> 429 `per_key_grant_cap` (or owner cap); PermissionDenied site policy (`BROWSER_SITE_DENIED`) -> 403 as `/v1/browser/grants` does; Unavailable -> 503.
- DELETE: broker RevokeGrant as the key; OK and NotFound both -> 204 (idempotent, never says whether the id exists for another key); PermissionDenied (switch off) -> 403.
- Flag interplay: `MODEL_GATEWAY_BROWSER_KEY_GRANTS` default off -> both routes 404; on but broker switch off -> 403 `api_key_grants_disabled`. Hosts never logged under ZDR.
