Review is not in the 8 days | plan WS17.E1 risks | owner decision; counsel and security sign-off outside the branch.

- [medium] [kind bug] Cache populate race: a `get` that read the old row can set the Redis entry after a concurrent `put`'s invalidate, leaving a stale envelope for up to the 1 h TTL. Same class as the legacy CachedProfileStore | crates/quarry-runtime/src/cached_profile_store.rs `CachedBlobStore::get` | needs a versioned cache key or a re-read guard; the stale envelope still decrypts (AAD holds), so this is staleness, not disclosure.
- [medium] [kind bug] Route mapping: `KeyError::Unavailable|Destroyed` becomes `ErrorCode::RuntimeNotReady` with the message `profile key unavailable`. The plan asks for HTTP 503 with `details.reason="profile_key_unavailable"`. The `details` field is not set; profile_routes.rs (U30 file) maps errors generically | crates/quarry-runtime/src/envelope_profile_store.rs `key_err`; crates/quarry-edge/src/profile_routes.rs | route-level detail deferred; check the error envelope in the test phase.
