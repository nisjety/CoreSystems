# Depth bullets, W3-B2-06 (E3.6-9 parse cache module)

- [severity high] [kind risk] The cache key is the SHA-256 of the source bytes only; the parser id, parser version and options are not in the key, so the same bytes parsed by two parser versions would share an entry | quarry-transform/src/parse_cache.rs ParseCacheKey | the wiring slice (E3.6-2/E3.6-4) must add a parser-version field before any caller uses the cache.
- [severity high] [kind test] Unit tests in parse_cache.rs were compile-checked only (cargo check --tests), never run | quarry-transform/src/parse_cache.rs tests module | build-first rule for this wave; run cargo test -p quarry-transform at the end of the wave.
- [severity medium] [kind hardening] Bound is entry count only; a parsed DOCX or PDF output can be large, so memory is not bounded in bytes | quarry-transform/src/parse_cache.rs ParseCache::new | byte budget needs the parsed value's size, which is not defined yet (E3.6-2 output type).
- [severity medium] [kind risk] No TTL and no per-org purge; an org's parsed output stays in process memory until eviction or restart, with no retention hook for org deletion | quarry-transform/src/parse_cache.rs | retention policy owner (WS4 / ADR topic 4) has not decided the rule.
- [severity medium] [kind other-plane] The cache is in-process only; a Redis or Postgres-backed copy (as in quarry-edge cache.rs for pages) is not built, so a multi-replica deployment gets no shared hits and a per-replica tenant boundary only | quarry-transform/src/parse_cache.rs | not in the E3.6-9 scope; needs the storage decision.
- [severity low] [kind doc] The ZDR rule is enforced by the caller passing ZdrMode on each call; a caller that passes ZdrMode::Off by default would bypass the rule | quarry-transform/src/parse_cache.rs get and put | the wiring slice must take ZdrMode from the request context, reviewed there.
- [severity low] [kind evidence] No metrics (hit, miss, eviction counts) are emitted | quarry-transform/src/parse_cache.rs | logging and metrics are out of scope for a pure module; the wiring slice adds counts, class labels only (log-field lint).
