# Depth findings left by D-B1-w1-security (2026-10-27)

- [severity high] [kind bug] D2-012 PARTLY fixed (enforcement in, producer out). Commit ff496d2fd adds CallerClass + effective_actor in domains/browser.rs: a verified service principal is always the agent (reload refused, takeover refused, cannot flip control, step and tab calls go out as agent), under a user session the stated actor is taken and can only tighten. Nothing produces ServicePrincipal yet: the gateway authenticates only Better Auth sessions (AuthenticatedUser, middleware.rs) and how the Model Plane authenticates to it when driving browser actions is an open owner decision. Left to do after that decision: (1) middleware.rs inserts Extension<CallerClass> from a verified service credential; (2) the actions surface (handlers.rs -> dispatchers.rs dispatch_browser_run_action / create_tab / select_tab / close_tab) forwards it, those four dispatchers pass None now; (3) the live-view socket (browser.rs ~2569) still trusts the client frame actor (a person's channel). Not changed on purpose: the SPA call at KnowledgeComposer.tsx:1065 sends actor agent under the user's own session, which only tightens, so removing it would loosen it. A user session that states human while being a model cannot be detected at the gateway at all; only a separate agent credential closes that.
- [severity medium] [kind risk] D1-001: the process-local RunStartGuard (live-run claim) is now backed by a durable rule. The broker reports the key a grant was issued under (ValidateGrantResponse.session_key = 54, Model Plane proto + browser-broker; broker already stored it) and model-gateway resolve_browser_grant refuses a presented run grant whose session_key is a gateway run key (browser-...) other than the starting run's: 409 browser_grant_in_use, no restart/replica/ended-run window. Correction of the earlier note: this was a Model Plane cross-service change, not another plane. Still open: (a) a run grant a CALLER derived itself (any session_key not starting browser-) and a broker that predates the field are covered only by the process-local claim (replicas, restart, and a grant whose run ended can still be reused); closing that needs a broker-side consumed mark (a new ClaimRunGrant RPC + column) or a decision that every presented run grant must carry a gateway key; (b) the guard fails open at 10,000 entries.
