    cd "apps/Ingestion Plane/Quarry-v2/crates/quarry-transform/tests/fixtures/documents"
    python generate.py

Needs Pillow. Edit the DOCS list in generate.py, not corpus.json or the PDFs. The generator refuses to write when a PII value fails its check.

## Traps found

- Pillow's default font decides the scan raster bytes. A Pillow upgrade changes the sha256 in corpus.json and the loader's sha256 test fails until the set is regenerated.
- The PDFs and DOCX are marked `binary` in `.gitattributes` in the fixtures folder. Keep that file; a CRLF conversion would break the sha256 check.
- `git diff --cached` showed two staged files of another unit before the first commit of this unit. `qcommit.sh` commits only its own paths, so they stayed staged. Do not run a bare `git commit` in this worktree without checking the index.
- `RUNBOOKS.md` had another unit's uncommitted hunks, so this unit did not add a RUNBOOKS section; the slice doc is its own file.
