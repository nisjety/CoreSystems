## Assumed decisions

1. The browser side is inherent `ChromiumoxideDriver` methods, not new `BrowserDriver` trait methods: `lib.rs` is outside this unit's files. The runtime `OtpFillTarget` adapter (E3.1-d seam) needs a `ChromiumoxideDriver` handle or a later trait method to call them (depth D-E31c-1).
2. "Frame origin equals top": the target must be in the top frame (`frame_id` none or the root frame id, and `window === window.top` in the page); the root frame `securityOrigin` must equal the top URL origin; both must equal the grant origin (tuple origins, default ports normalised). A child-frame code field is refused (`otp_not_top_frame`), even same-origin.
3. "Exactly one visible required non-password input": the target is a visible `<input>` of a text type (text, search, url, tel, email, number), not password, `required` or `aria-required="true"`, and the document has exactly one visible text field (inputs of those types, textareas, contenteditable). Password fields are not counted and do not refuse.
4. "No options/QR": a `list` attribute on the target, or any visible select, radio, radiogroup, listbox or option, refuses (`otp_options_present`); any visible img/canvas/svg/object/picture whose id, class, alt, title, aria-label, src or data-testid names a QR code refuses (`otp_qr_present`). The probe returns booleans only.
5. Refusals are 403 `FORBIDDEN` with a closed `otp_*` reason (also `otp_loader_changed` when the top-frame loader changed between precheck and insert), not 409: the run needs a new observation and a new approval anyway.
6. The insert re-checks every precondition right before `Input.insertText` (no gap between the precheck and the code read) and always uses trusted input, whatever `QUARRY_BROWSER_TRUSTED_INPUT` says.
7. https only; loopback http is accepted only under `cfg!(test)` in this crate (for a later live fixture test). The runtime fixture `/otp-login` is http, so a runtime-level live proof needs an https fixture or its own allowance (depth D-E31c-3).
8. `current_loader_credential_delivered` fails closed: when the session has a mark and the top-frame loader cannot be read, it answers delivered.
