## Design

Activity pool, not child workflows: each page runs `runPageSnapshot` in a `workflow.Go` coroutine and writes its result into its URL's slot; `workflow.Await(inFlight < limit)` bounds the pool. Before each launch the reused `controlGate` runs (installControlHandlers from batch-control-v1): pause holds new launches while running pages finish; cancel launches no more, drains the running pages, then emits run_cancelled with pending = URLs not launched. Statistics, failed/visited and pages_blocked(_robots) are aggregated in URL order after the drain, so they do not depend on completion order. Per-page events (page_fetched / page_failed) are emitted by each page as it ends, so their order in the stream is completion order.

## Flag and default

`QUARRY_BATCH_PARALLEL` on the orchestrator worker, default **off** (unset/0/false/off/no = the sequential batch exactly as before, apart from the two new history markers). `true`/`on`/`yes` = 4 pages at a time; a positive integer N = N, clamped to 16; unparseable = off. Then capped by the job's `max_parallel` and by the URL count; 1 is sequential.

## Assumed decisions

- Activity pool in the workflow over child workflows (the scope allows either): no new workflow type to register, no change to ids, events or the dispatcher.
- The flag is read in the workflow through a recorded `SideEffect`, not passed by the dispatcher: the unit's files are the workflow and the inputs only, and the side effect keeps replay deterministic (the recorded value wins). Cost: every new batch execution records the version marker and one side-effect marker even with the flag off.
- "Max by org limits" = `params.max_parallel` on the job, which nothing stamps yet (see depth D-E372-1); until then only the flag and the hard max of 16 bound it.
- Results order = aggregation in URL order; there is no per-URL result list in the terminal event today, so none was added.
- A page in flight when cancel arrives is allowed to finish (same as the sequential batch, which never interrupts the current page).
