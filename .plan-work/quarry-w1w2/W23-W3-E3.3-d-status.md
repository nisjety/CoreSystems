## Assumed decisions

1. Route home: `browser_evidence.rs` (the queue's file), path `/api/v1/browser/sessions/{id}/attachments/region`, owner-gated by the same Quarry projection as the evidence routes, rate class Interactive.
2. Crop in the browser, check in the gateway. The gateway has no image decoder, so it cannot crop or rescale pixels; it re-resolves the tab and the region and checks that the image is a PNG/JPEG of the resolved region's shape. It cannot prove that the pixels came from the frame (depth D-E33d-1).
3. Only the active tab can be attached: the streamed frame shows only the active tab, so a known but inactive tab is refused (`tab-not-active`).
4. ZDR: refused, and a projection that does not state `zdr` is refused the same way (the receipts rule in this module).
5. The attachment is ephemeral and returned to the caller only; the gateway stores nothing and Quarry is not asked to store anything. Carrying it into a chat turn is the composer's and Model Plane's job (MP ask).
6. "Selection" is optional selected text sent with the region, treated as page content (browser-scraped), cleaned of control characters and capped at 4000 chars. The gateway cannot verify it against the page.
7. Limits: 1 MiB decoded image (keeps the base64 JSON under the default 2 MB body limit, so no `DefaultBodyLimit` change), 8 px minimum edge, image at most 3x the region, 5 percent aspect tolerance, client crop longest edge 1600.
8. Wire name of the trust class: `browser-scraped`, as `TrustClass::BrowserScraped.as_str()` in `mp-content-safety/src/trust.rs`.
