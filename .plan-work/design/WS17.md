## Design

### D0 Vocabulary and the two rules
- **Contained thread**: `threads.space_id IS NOT NULL AND space_kind IS DISTINCT FROM 'personal'`. A missing kind (every pre-existing thread, scheduled threads) is contained: fail closed.
- **Rule M1 (write)**: nothing said in a shared room is learned into personal or tenant memory.
- **Rule M2 (read)**: a shared-room turn recalls only memory whose label says the whole current audience may have it: rows of this thread, room memory of this Space (labelled, at or below the thread's audience revision), or an owner-signed disclosure.
- **Personal agent** = an agent definition with `visibility='owner'` and an owner recorded at Control. In a room it is a persona plus a roster entry. Its memory in the room is room memory; its owner's personal memory is reachable only through D5.

Order of checks and reason codes: `space_not_active`; `personal_space_not_supported` (a personal Space stays single-subject; the owner's assistant there is the private panel); `room_role_insufficient` (owner or manager only, parity with `CREATE_AGENT_ROLES`); `agent_suspended`; `agent_not_visible` (visibility `owner` and actor is neither owner nor listed; mapped to 404, never revealing existence); `add_policy_nobody`; `add_policy_owner_only` (actor must be owner or listed); for `visibility='owner'`: `personal_agents_not_entitled` (org bit, D4) then `owner_not_in_room` (the owner must be an active member of the room: invited with the owner's consent, since only the owner or a person the owner listed can add it). ## Open questions for the user

6. Do you want existing unowned org agents claimable by their creators, and by whom when `createdBy` is empty (room-created agents never set it)?
7. May the one-time legacy quarantine mark older room-origin memories as withheld without asking each owner first?
