|---|---|---|
| Boundaries, failure card, chunk recovery, watchdog, banner, link safety, viewer registry, chips, tab, avatar, hover card | Frontend SPA (`FV/src`) | pure presentation |

### D2 F-t1-024 client resilience (Frontend plus gateway)

**RegionBoundary** (`FV/src/shared/ui/resilience/RegionBoundary.tsx`): wraps `Errored`. Props `region: 'root'|'navbar'|'sidebar'|'outlet'|'space-tab'|'panel'`, `resetKey?: () => unknown` (an effect calls `reset()` when it changes, so navigation or a Space switch clears a failed region), `compact?: boolean`. Placement: root in `index.tsx:9` around `<App />`; in `CoreShell.tsx` one boundary each around `CoreNavbar` (:102), `CoreSidebar` (:121) and the outlet (:131, `resetKey` = `location.pathname`), so a page crash keeps navigation alive; in `SpaceCockpit.tsx` around each tab panel body (:224-231, `resetKey` = tab id). The WS01 AuxPane and WS09 run card wrap themselves with `region="panel"`.

**Classification** (`classify-client-error.ts`, pure): `stale_deploy` when the message matches `Failed to fetch dynamically imported module`, `error loading dynamically imported module`, `Importing a module script failed` or `Unable to preload CSS`; `session_expired` for `ApiError` 401 or code `unauthenticated`; `gateway_unreachable` for `TypeError: Failed to fetch` or `ApiError` 502, 503, 504; else `render_error`. Card (`FailureCard.tsx`): title and one sentence per class (Norwegian first via `useI18n().tr`, copy in `failure-copy.ts`, not in the API error seam), `role="alert"`, buttons Reload (`location.reload()`), Retry (the boundary `reset()`; hidden for `stale_deploy`), Sign in (session class), and Copy details. Copy details is `{class, build_id, region, at, route_class}` where `route_class` is the first path segment only. It never includes the error message, URL query, ids or content.

**Chunk recovery** (`FV/src/shared/build/chunk-recovery.ts`, imported first in `index.tsx`): on `vite:preloadError`, if `sessionStorage['verevon.chunk-reload']` is absent or older than 60 s, store `Date.now()`, call `event.preventDefault()` and `location.reload()`; otherwise do nothing so the error reaches the nearest boundary as `stale_deploy`. All storage access in try/catch.

**Boot watchdog** (`FV/public/boot-watchdog.js`, classic script, served `no-cache`, loaded from `index.html` before the module script because CSP forbids inline script): after 15 s without `window.__verevonBoot === true` (set by `index.tsx` after `render`), fetch `/version.json`; if its `build_id` differs from `<meta name="verevon-build">` do the same guarded single reload; else paint a plain-DOM card (Reload, language from `localStorage['verevon.locale']`) and `navigator.sendBeacon('/api/v1/client-diagnostics', {kind:'watchdog'})`.

**Build id and stale-tab check**: `vite.config.ts` gains `define: {__VEREVON_BUILD_ID__: JSON.stringify(SOURCE_REVISION||'dev')}` and a small plugin that emits `version.json` `{"build_id","built_at","client_contract"}` in `generateBundle` and injects `<meta name="verevon-build">` in `transformIndexHtml`. `Dockerfile` redeclares `ARG SOURCE_REVISION BUILD_DATE` and `ENV`s them in the `build` stage before `RUN pnpm build`; the CI `docker buildx build` passes both. `FV/src/shared/build/version-check.ts` fetches `/version.json` with `cache:'no-store'` at start, on `visibilitychange` (visible after at least 5 min hidden), on `online`, every 15 min while visible, and after a `stale_deploy` card. A response whose `Content-Type` is not JSON is ignored (this is what the SPA fallback returns until the nginx rule ships). `build_id !== BUILD_ID` and `BUILD_ID !== 'dev'` shows `NewVersionBanner` (non-blocking `role="status"`, Reload, dismiss for the session keyed by the new build id). Other trigger sources (SSE reconnect) call the exported `checkClientVersion()`; WS02 wires it, WS07 does not edit `sse.ts`.

**nginx** (`FV/nginx.conf`): move the five re-emitted security headers (nosniff, Referrer-Policy, X-Frame-Options, Permissions-Policy, HSTS), the enforced CSP and the new Report-Only header into `FV/nginx-security-headers.conf` (Dockerfile `COPY` to `/etc/nginx/snippets/verevon-security-headers.conf`) and `include` it in the server and in every location that uses `add_header`, ending the "keep in sync" comment (:42, :107, :122). Add `location = /version.json` (`Cache-Control: no-store`, `default_type application/json`, `try_files /version.json =404`), `location = /index.html` (`Cache-Control: no-cache`), `location = /boot-watchdog.js` (`no-cache`; exact match beats the 1-year regex at :103). An internal `try_files` fallback to `/index.html` re-enters locations, so deep links get `no-cache` too.

**Gateway** (`GW/domains/client_config.rs`, merged in `main.rs` build_router beside `chat`, registered in `domains/mod.rs`): all three routes public (no `require_session`, because a crashed or logged-out app must still reach them), IP rate-limited by the existing middleware.

| Route | Request | Response | Errors |
|---|---|---|---|
| `GET /api/v1/client-config` | none | `200 {"data":{"contract":1,"min_contract":1,"policy":"banner","revision":"<SOURCE_REVISION>","build_date":"..."}}`, `Cache-Control: no-store` | none |
| `POST /api/v1/client-diagnostics` | `{"kind":"render_error\|chunk_error\|watchdog","build":"<=12 hex chars"}`, body cap 512 B | `204` | `400 {"error":{"code":"invalid_diagnostic","message":"...","details":{}}}` for any other shape |
| `POST /api/v1/client-diagnostics/csp-report` | `application/csp-report`, `application/reports+json` or `application/json`, body cap 8 KiB | `204` | `400 invalid_report`, `413` by the body limit |

The diagnostics route increments `verevon_client_failures_total{kind, build_match="current"|"other"}` through the existing Prometheus recorder (`observability.rs`) and stores nothing. The CSP route increments `verevon_csp_reports_total{directive, disposition}` with `directive` mapped to a closed set (everything else is `other`). It never logs or labels the blocked URL, document URL or sample, except when `CSP_REPORT_LOG_HOSTS=1` AND `dev_flags_allowed(APP_ENV)` (`config.rs:429`): then the blocked ORIGIN (scheme and host only) is logged at info, for the host inventory in a non-production environment (decision WS07-D6). Constants: `CLIENT_CONTRACT: u32` and `CLIENT_MIN_CONTRACT: u32` live in `GW/client_contract.rs`; the SPA mirrors `CLIENT_CONTRACT` in `FV/src/shared/build/client-contract.ts`; a node test (`FV/apps/gateway/scripts/client-contract-parity.test.mjs`, added to the `pnpm test` list in `FV/package.json`) fails when the two differ. The rule is written in both files: bump `CLIENT_CONTRACT` for a gateway change older bundles cannot survive; raise `CLIENT_MIN_CONTRACT` only to force upgrades. `policy` comes from `AppState.client_policy` (env `CLIENT_VERSION_POLICY` = `off|banner|enforce`, default `banner`), never read from `std::env` in a handler.

**Contract mismatch** (`CLIENT_CONTRACT < min_contract`): sticky banner "This version is out of date. Reload." The client auto-reloads only when `policy === 'enforce'`, the page has been hidden at least 30 s, and `hasUnsavedWork()` is false with at least one probe registered (`FV/src/shared/build/unsaved-work.ts`: `registerUnsavedWork(key, probe) => unregister`). Until composers register (WS01-S6, WS15) `enforce` behaves as `banner`. Composers are not edited by WS07.

```sql
WITH rows AS (
  SELECT m.thread_id, m.id AS message_id, m.created_at, m.sequence, m.agent_name,
         a.e->>'id' AS artifact_id, a.e->>'kind' AS kind, left(a.e->>'title',200) AS title,
         COALESCE((a.e->>'version')::int,1) AS version, char_length(COALESCE(a.e->>'content','')) AS size_chars
  FROM threads t JOIN messages m ON m.thread_id = t.id
  CROSS JOIN LATERAL jsonb_array_elements(CASE WHEN jsonb_typeof(m.metadata->'artifacts')='array'
        THEN m.metadata->'artifacts' ELSE '[]'::jsonb END) AS a(e)
  WHERE t.org_id=$1 AND t.space_id=$2 AND t.archived_at IS NULL
    AND (t.recipient_audience_revision IS NULL OR t.recipient_audience_revision <= $3)
    AND m.space_id=$2 AND m.role='assistant' AND jsonb_exists(m.metadata,'artifacts')
    AND (m.recipient_audience_revision IS NULL OR m.recipient_audience_revision <= $3)
    AND a.e->>'kind' IN ('document','code','html'))
SELECT DISTINCT ON (thread_id, artifact_id) rows.*, count(*) OVER (PARTITION BY thread_id, artifact_id) AS version_count
FROM rows ORDER BY thread_id, artifact_id, version DESC, sequence DESC
```
