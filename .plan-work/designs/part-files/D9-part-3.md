
## 4. Slices (PR-sized, in build order)

Common rules for every slice.

- Baseline first. In a worktree, `pnpm` prunes `pnpm-lock.yaml` (restore it with `git checkout -- "apps/Frontend Plane/verevonv3/pnpm-lock.yaml"` after the last pnpm call), `node_modules` is absent (`pnpm install --prefer-offline`), and `:5173` serves the main checkout, not the worktree (memory note `verevonv3-worktree-verification`). Capture the failing sets before editing: `pnpm exec vitest run --reporter=json --outputFile=<scratchpad>/vitest-baseline.json`, `pnpm typecheck`, `pnpm lint`, then diff after. Do not trust exit codes; the known baseline (12 failing vitest files, 21 typecheck errors in `quarry-client.ts`, lint dying on typescript-eslint) is from 2026-09-06 and was not re-measured in S9.
- Gates per PR (from `FE`): `pnpm lint`, `pnpm typecheck`, `pnpm test` (runs four `node --test` gateway scripts including `action-surface-contract.test.mjs`, then `vitest run`), `pnpm build`, and `cargo test --manifest-path apps/gateway/Cargo.toml --all-targets` (CI runs `cargo fmt --check`, `cargo clippy --all-targets -- -D warnings`, `cargo test` in `GW/..`, `verevonv3-ci.yml` L132-141). Quarry changes: `cd "apps/Ingestion Plane/Quarry-v2" && cargo test -p quarry-edge <name>` inside the `rust:1` container recipe (host cannot build Quarry; memory note `quarry-rust-tests-in-docker`; a full run takes over ten minutes). Model Plane: `cd "apps/Model Plane/rust" && cargo test -p execution-core --lib <name>` (two known Windows-only broken targets, memory note `model-plane-build-and-deploy`).
- Playwright is not in CI (S9 H8, section 4.3). New specs are named `browser-workspace-*.spec.ts` so they run in the existing `local` project without a config change; run `cd "apps/Frontend Plane/verevonv3" && pnpm exec playwright test --project=local tests/e2e/<spec>` against `LOCAL_E2E_BASE_URL` (default `http://localhost:5173`).
- Files with CRLF working copies (`browser-omnibox.ts`, `KnowledgeComposer.tsx`; `global.css` warns the opposite way) must keep their line endings; do not run a repo-wide formatter on them.
- Every new UI string goes through `useI18n().tr(no, en)`; every new gateway error code gets a `no`/`en` row in `shared/i18n/errors.ts`.
- Deployment evidence for the SPA: `docker restart frontend-plane-verevonv3-frontend-1`, wait for HTTP 200 on `:5173`, then in the page `await fetch('/src/styles/global.css', {cache:'reload'}); location.reload()` (memory note `verevonv3-vite-needs-restart`). Gateway: `docker build -t frontend-plane-verevonv3-gateway:latest -f "apps/Frontend Plane/verevonv3/apps/gateway/Dockerfile" "apps/Frontend Plane/verevonv3/apps/gateway"` then `python3 C:/dev/tools/swap_gateway_image.py`. Quarry edge: recreate with the env-file chain from memory note `ingestion-plane-deploy-recipe` (`docker compose -p ingestion-plane <env-files> -f "apps/Ingestion Plane/docker-compose.yml" up -d --no-deps --build quarry-edge`). Model Plane: `bash "apps/Model Plane/scripts/compose.sh" up -d --no-deps --build execution-core model-gateway`. The repo counts a claim only after rebuilt images, a running stack and the stated flow.
