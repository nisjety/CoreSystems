
## 4. Slices (PR-sized, in build order)

Conventions for every slice. Quarry Rust does not build on the Windows host ([MEM] quarry-rust-tests-in-docker): run inside a `rust:1` container with the `quarry-cargo`, `quarry-go` and `quarry-target` volumes and `bash -c` (never `bash -lc`); a full `cargo test -p quarry-core -p quarry-runtime -p quarry-edge` exceeds ten minutes, so commands name crates. CI: `cargo check --workspace` and `cargo test --workspace` at `.github/workflows/quarry-v2-ci.yml:201-205` (hard gate). Model Plane Rust on Windows: `cargo test -p <crate> --lib` ([MEM] model-plane-build-and-deploy; two targets fail pre-existing), CI `cargo test --workspace --no-fail-fast` (`model-plane-rust-ci.yml:119`, plus the golden sync at 95-96). Control Plane: `cd "apps/Control Plane/auth-core" && npx jest <spec>` after one `pnpm install`; the baseline has 15 failing tests in 3 suites, so diff failing sets, do not trust the exit code; worktree files are CRLF and the vendored-manifest check hashes the LF-normalised bytes ([MEM] auth-core-local-testing). Contract sync: `bash scripts/tests/zdr-contract-sync.test.sh` (and `--self-test`). Docs gate: `node --test "apps/Ingestion Plane/Quarry-v2/scripts/tests/docs-contract.test.mjs"` and `node --test scripts/tests/quarry-model-plane-switches.test.mjs` (both [U], green today per the S9 sweep). "Deployment evidence" follows the repo rule: rebuilt local image, running stack, a verified end-to-end flow. Quarry edge rebuild: `cd "apps/Ingestion Plane"` and the compose env-file chain of [MEM] ingestion-plane-deploy-recipe with `up -d --build quarry-edge` (the Makefile `make up` passes two env files and may under-interpolate); model-gateway: `bash "apps/Model Plane/scripts/compose.sh" up -d --no-deps --build model-gateway` ([MEM]); Auth Core: `bash "apps/Control Plane/scripts/run-control-plane.sh"` ([MEM] control-plane-build-and-deploy: a bare `docker compose build` exits 0 and does nothing); gateway image swap and SPA restart per the ingestion recipe ([MEM] verevonv3-vite-needs-restart).

Evidence tiers (DEC-17): **E1** real model-gateway reached with the dev bypass (`CROSS_PLANE_AUTH_DEV_BYPASS`, refused in production by `main.rs:174-176`), proves the engine only; **E2** real Auth Core mint of both tokens, real gateway and inference-core, the only tier that supports the claim "the grant works".

Build order: **0**, then **1** (Model Plane) in parallel with **3 to 5** (Quarry engine, no grant needed), **2** (grant, approval-gated) as soon as DR-15.1 is ruled, then **6** (needs D5 slice 4 and slices 3 to 5; E2 needs 1 and 2), then **7**; **8** is independent and can run first or last; **9** is design-level.
