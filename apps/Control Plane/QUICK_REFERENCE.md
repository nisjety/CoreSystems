# Quick Reference: Control Plane Data Ownership

## ✅ What Control Plane Owns

### org-core Service
- ✅ orgId (generated by auth-core, stored in org-core)
- ✅ plan (free, pro, enterprise)
- ✅ quotas (api_calls, users, storage_mb)
- ✅ capabilities/entitlements (feature flags)
- ✅ role mappings (owner, admin, member, viewer + custom)
- ✅ billing flags (subscription status, payment info)
- ✅ compliance settings (GDPR, HIPAA, SOC2, data residency)
- ✅ hard deletes (GDPR purge via PostgreSQL functions)

### auth-core Service
- ✅ authentication (email/password, OAuth, SSO, 2FA, passkeys)
- ✅ user profiles (email, name, phone, role)
- ✅ sessions (tokens, device tracking)
- ✅ organization memberships
- ✅ hard deletes (GDPR purge via PostgreSQL functions)

## 📡 Events Emitted

### Organization Events
- `organization.created` - When org is created
- `organization.updated` - When org metadata changes
- `organization.plan.changed` ⭐ NEW - When subscription plan changes
- `organization.deleted` - When org is deleted

### User Events
- `user.created` ⭐ NEW - When user registers
- `user.updated` ⭐ NEW - When user profile changes
- `organization.member.added` - When user joins org
- `organization.member.removed` - When user leaves org

## 🔄 Convex Role

**Convex is a READ-ONLY consumer** of Control Plane data:
- Subscribes to NATS events
- Maintains local projection with `externalOrgId` and `externalAuthId`
- Cannot create/update orgs or users
- **Owns** conversations and messages (writable)

## 🔐 GDPR Functions

### User Deletion
```sql
-- Hard delete (irreversible)
SELECT gdpr_hard_delete_user('user_id_here');

-- Anonymize (softer option)
SELECT gdpr_anonymize_user('user_id_here');
```

### Organization Deletion
```sql
-- Soft delete (can be recovered)
SELECT soft_delete_organization('org_id_here');

-- Hard delete (irreversible)
SELECT gdpr_hard_delete_organization('org_id_here');

-- Purge old deleted orgs (>30 days)
SELECT purge_old_deleted_organizations(30);
```

## 📊 Database Tables

| Table | Purpose |
|-------|---------|

| `org_quotas` | Resource limits (API calls, users, storage) |
| `org_billing` | Subscription and payment info |
| `org_compliance` | GDPR, HIPAA, SOC2 settings |
| `org_role_mappings` | Role-based permissions |
| `org_plan_history` | Audit trail of plan changes |
| `org_entitlements` | Feature flags (existing) |

## 🎯 Key Points

1. **Control Plane = Source of Truth** for all org/user data
2. **Convex = Consumer** of org/user data (read-only projection)
3. **NATS = Event Bus** connecting Control Plane to consumers
4. **GDPR Compliant** with hard delete functions
5. **Multi-tenant Ready** with quota and permission systems
