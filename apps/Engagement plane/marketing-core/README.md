# Marketing Core

Owner of cross-channel campaign planning, campaign briefs, coordinated launches,
budget/approval policies and campaign execution receipts in Engagement Plane.
Social publishing stays in Social Core. Lead generation and person records stay
in Leads Core. Tender workflows stay in Anbud Core.

SEO/SEM analysis, search reporting, technical audits, search trends, competitor
search research and search-ad performance belong to Visibility Core. Paid search
execution must use Marketing's future campaign approval/budget boundary and
Integration Core's provider authority; a report must never activate spend.

There is no campaign API/container implemented in this directory yet. The
previous service named marketing-core has moved to ../visibility-core. Its old
Docker/HTTP/env identifiers remain compatibility contracts during migration;
they must not be mistaken for a second campaign backend or duplicate data owner.
