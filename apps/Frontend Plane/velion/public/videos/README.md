# Videos Directory

Place your video wallpaper file here:
- `wallpaper.mp4` - Background video for the demo page

The video is referenced in `/app/(public)/demo/page.tsx` and will auto-play, loop, and be muted.

**Recommended video specifications:**
- Format: MP4
- Resolution: 1920x1080 or higher
- Duration: 30-60 seconds (looped)
- File size: Keep under 10MB for faster loading
