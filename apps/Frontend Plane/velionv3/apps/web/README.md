# Velion Web

Customer-facing Next.js site for Velion. This is separate from the SolidJS
workspace app at the `velionv3` root and is intended to give customers a first
feel for the AI-native customer experience product.

## Scripts

```bash
pnpm dev
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm verify
```

The dev server runs on port `3212`.
