## Selection and delivery

Compared Pexels MCP and Unsplash plugin results in the actual 4:5 card proportions. Preferred legible work situations, natural depth and a coherent palette over generic screen portraits, neon lighting and monochrome stock. The Unsplash signing photograph was also in the existing Verevon collection and matches the original Trust reference.

All original photographs have a longest edge above 3840 pixels. Assets use direct provider URLs. Next Image delivers responsive versions at quality 90; the `sizes` hint accounts for the extra source width needed when a landscape photograph covers a portrait card. Each displayed card uses an appropriately sized version rather than a full 4K download. Descriptive alternative text identifies the visible activity without implying the photographed people use or endorse Verevon.
