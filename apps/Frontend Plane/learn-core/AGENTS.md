# Learn Core clients

- Marketing is Next.js/React. Dashboard is Vite/Solid **2**, not Solid 1. Pin prerelease framework/web/plugin versions compatibly.
- Windows companion is C#/.NET with native WPF UI. macOS is deferred. Privileged native actions must remain outside untrusted webpage content.
- Shared behavior belongs in framework-independent packages or versioned contracts. Reuse remote-core at `../verevonv3/packages/remote-core`; do not fork it or claim C# can import TypeScript directly.
- No client-side identity headers, fake authentication, fabricated progress or active device grants. Surface missing connections honestly.
- No hosted fonts, telemetry, CDN assets or cloud AI in the strict-self-hosted foundation.
- Do not collect passwords to impersonate students or implement hidden background screen capture. Distinguish Teachme login, device enrollment and authorized assistance.
- Keep public marketing separate from authenticated school data. A Vite proxy is development routing, not a production authorization boundary.
- Verify web with `pnpm typecheck`, `pnpm test`, `pnpm build`. Verify desktop with .NET 10 build and native self-check. Build outputs/SDKs stay ignored.
