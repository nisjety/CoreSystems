Cache Warm-Hit Determinism

This article exists to verify that the warm-cache code path returns byte-identical content across two requests, where the second request reuses the cached blake3 fingerprint to short-circuit the transform pipeline.

The warm path is the most common production path; cold scrapes are a tiny fraction of overall traffic. Performance regressions in this path show up as latency cliffs at the edge.

What we verify

The eval harness fingerprints this fixture twice in succession. Both fingerprints must match byte-for-byte. Any divergence indicates a non-deterministic transform.
