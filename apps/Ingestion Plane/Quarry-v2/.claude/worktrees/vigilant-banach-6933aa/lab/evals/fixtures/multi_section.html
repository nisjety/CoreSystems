Developer Changelog: May 2026

A summary of new features, improvements, and breaking changes shipped this month.

New Features

We shipped three major features in May. The highlight is real-time collaboration on shared dashboards, allowing multiple team members to edit widgets simultaneously.

  • Real-time dashboard collaboration with conflict resolution
  • Custom webhook destinations for alert routing
  • CSV bulk import for configuration objects

Improvements

Query performance received significant attention this cycle. P95 search latency dropped from 180ms to 95ms after index restructuring.

  • Search index rebuild reducing P95 latency by 47%
  • Dashboard load time improved by 30% through lazy widget rendering
  • API rate limit headers now include retry-after timestamps

Breaking Changes

The v1 authentication endpoint has been removed after a six-month deprecation period. All integrations must migrate to the v2 OAuth flow.

  • Removed deprecated /api/v1/auth endpoint
  • Renamed team_id to workspace_id in all API responses

Bug Fixes

We resolved 14 bugs reported through the community tracker, including a critical timezone handling issue that caused incorrect scheduling.

  • Fixed timezone offset calculation for DST transitions
  • Resolved memory leak in long-running WebSocket connections
  • Corrected pagination cursor encoding for Unicode content
