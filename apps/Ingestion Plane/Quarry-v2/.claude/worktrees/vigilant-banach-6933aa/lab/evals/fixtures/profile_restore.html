Welcome back, authenticated user

This page is the post-login dashboard. Reaching it requires that the browser session carries the auth cookie and localStorage entries captured during the prior login flow.

Session-dependent content

The dashboard greets the user, displays workspace data, and links to account settings. Without a valid restored profile, the request would land on the login page instead.

The eval harness uses this fixture to simulate a profile-restore scenario: a SessionSnapshot is captured on a "logged-in" hydrated session, then a fresh session is rehydrated from the snapshot and verified to land on this dashboard rather than the login page.

What gets verified

The fingerprint of this page should be stable across capture-then-restore cycles. Cookies, localStorage, and viewport must all roundtrip intact for the simulation to be meaningful.
