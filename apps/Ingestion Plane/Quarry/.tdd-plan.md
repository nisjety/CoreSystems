## Phase 2: GREEN — Implement Validation

**File:** `internal/config/config.go`

Add validation method after the Load() function:

```go
// ValidatePublisherConfig ensures publisher settings are not partially configured.
// Both URL and token must be set together, or both empty.
func (c *Config) ValidatePublisherConfig() error {
    // Check Velion partial config
    velionHasURL := c.VelionNATSURL != ""
    velionHasToken := c.VelionNATSToken != ""
    if velionHasURL != velionHasToken {
        return fmt.Errorf("VELION_NATS_URL and VELION_NATS_TOKEN must both be set or both be empty")
    }

    // Check Shared partial config
    sharedHasURL := c.NATSSharedURL != ""
    sharedHasToken := c.NATSSharedToken != ""
    if sharedHasURL != sharedHasToken {
        return fmt.Errorf("NATS_SHARED_URL and NATS_SHARED_TOKEN must both be set or both be empty")
    }

    return nil
}
```

Call validation in `Load()` before returning:

```go
func Load() (*Config, error) {
    cfg := &Config{
        // ... existing initialization ...
    }

    if err := cfg.ValidatePublisherConfig(); err != nil {
        return nil, fmt.Errorf("invalid publisher config: %w", err)
    }

    return cfg, nil
}
```
