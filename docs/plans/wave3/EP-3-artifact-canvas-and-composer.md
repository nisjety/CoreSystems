## 2. Verified current state

**Artifact versions live in gateway memory plus message metadata.**
- `MG/artifacts.rs:1-21` states the model supplies the id and the gateway assigns the version. The store is `ArtifactVersionStore` (`MG/artifacts.rs:137-155`): `DashMap`s for versions, titles, current text, kind and the accepted source review. It is process-local.
- `lock_commit` (`MG/artifacts.rs:206-209`) is a per-thread `tokio::sync::Mutex` in this process. `unchanged_from` (`:211-213`) compares the run's fork with the shared store. So run-versus-run serialisation holds inside one gateway replica only [INF: two replicas do not share the mutex; nothing in the file says otherwise].
- Commit site: `MG/sse.rs:5008-5025` takes the lock and, if another run moved an artifact, ends the turn with `failure_code = "artifact_revision_conflict"` and a retryable error. After the durable save, `MG/sse.rs:5302-5318` seeds the store and emits one `artifact` event per id.
- Persistence: `session_flow::turn_evidence_metadata` (`MG/session_flow.rs:1938-1962`) writes `metadata.artifacts` on the assistant message. `RecordedArtifact` (`MG/sse_events.rs:1266-1309`) is `{id, kind, title, content, version}`, text kinds only (`document|code|html`), max 200,000 chars; data URIs are never persisted. `recorded_artifacts()` (`MG/sse_events.rs:1634-1660`) keeps only the latest version per id per turn, so intermediate in-turn versions are not stored.
- Rehydration: `rehydrate_persisted_artifacts` (`MG/sse.rs:6714-6760`) reads `metadata.artifacts` from each message that `load_recent_thread_messages` lists (`MG/sse.rs:6762-6830`, `include_inactive: false`), so only the active path of the message tree seeds the store.
- Model tools: `create_artifact` (`MG/tool_loop.rs:3377-3436`, title and near-miss id resolution, kind lock), `update_artifact` (`:3438`), `read_artifact` (`:3554`). Model output is not screened (it is the model's own text, comment at `:3418-3421`).
- No HTTP route reads or writes artifacts: the `/v1/threads/...` routes are `MG/http_routes.rs:247-302` and none of them is an artifact route. The BFF chat router lists 24 paths (`BFF/domains/chat.rs:16-80`), none for artifacts.
