**Judge building blocks.** The gateway already runs a pinned cheap side model for title, follow-ups and the source judge: `aux_model()` (`MG/sse.rs:9559`, default `gpt-4o-mini`), `verification_judge_request` (`:9579-9604`, temperature 0, fixed `max_tokens`, inherits ZDR), routed through `subscription_scoped_request` (`:802`). `execution-core/src/postcondition.rs` (2375 lines) holds deterministic postcondition verifiers, but they are action-specific (the first is shipping bookings, `:38-45`); for a general goal they will almost always answer Inconclusive.

The ZDR chat path has no tool loop and Do is refused under ZDR, so a goal cannot run under ZDR at all.

**Audit staleness.**

2. "The scheduled-step lane is one tool-less 1,024-token inference per step (`execution-core/src/grpc.rs:496-525`), which cannot continue a Do run": stale. ### S1 - Goal record, goal bar and a manual Continue [BUILD]

**Goal.** A person sets a goal on a thread (objective, optional success criteria). It shows as a bar above the composer with Edit, Pause and Clear. Every agentic turn on that thread recites the goal to the model as data. A "Continue" button sends one continuation turn. No budget enforcement, no judge, no automatic turn. This is the cheapest real value: a long task keeps its aim across turns and reloads.

## 7. Risks and what the owner must decide

**Risks.**
1. Authority creep: an auto-sent turn looks like the user typing. Mitigated by D4 (visible countdown, hidden-tab stop), D5 (server refuses a claim while anything is pending) and honest transcript text. A durable plan grant still covers every later run on the thread for 24 h (W2-47 open item); a goal makes that property more visible, not wider.
2. Spend: budgets count metered tokens only; on the subscription route only the turn cap bounds a goal. Failed runs may report no usage (D2-005). The per-run ceiling is per turn and its precedence can loosen the org cap (D2-698/699 P0); S2 clamps, WS27 must fix the root.
3. Judge errors: a false `met` closes a goal early, a false `not_met` spends turns. Evidence rule, user override and the turn cap bound both.
4. Hot files: `MG/sse.rs`, `MG/http_routes.rs`, `use-chat-controller.ts`, `ComposerTrays.tsx`, `SC/src/grpc.rs`. Follow the edit-first rule of plan section 4.5.
5. S6 inherits WS20's open P1 rows; it must not start before its gate.
6. Usage reconciliation: the goal ledger and cost-core can disagree while `MODEL_GATEWAY_AGENT_USAGE_ENVELOPE` is off. The goal ledger is the budget authority for goals; cost-core stays the billing authority.
