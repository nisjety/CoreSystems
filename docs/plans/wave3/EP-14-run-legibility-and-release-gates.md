## 5. ZDR clause

**Rule.** Every new durable record in this epic is written only for a run whose retention decision is `persistent`. ZDR runs and waived runs (DEC-32, D13) write nothing to any new store: no snapshot, no digest, no timing row. Reads refuse a ZDR bearer with a typed refusal. No new egress: nothing new is published on NATS, no snapshot or timing data is logged (WS12-S10 log-content gate), no third-party destination.
