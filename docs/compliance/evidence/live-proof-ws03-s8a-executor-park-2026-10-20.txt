FINDING (a defect no unit test saw, found by this proof)
  The park events RunParked and RunResumed were refused by session-core: the executor logged "run_agent: failed to publish RunParked (best-effort)" and "failed to publish RunResumed (best-effort)" with grpc code InvalidArgument on every park and every resume. Cause: session-core's RecordOrchestrationEvent allowed those two tags only for the principal service:execution-core, but the executor records every run event under the RUN OWNER'S delegated bearer (the same path SubagentStopped uses), so its own park events never matched. Effect: best-effort and display-only. The run_parked frame the client sees comes from the RunAgent response and was unaffected; no RUN_PARKED or RUN_RESUMED row reached the event log and nothing else depended on one. Not shown by this proof: the events being recorded. The fix replaces the principal gate with the park-store switch (see the decisions ledger entry and the plan row for the commit).
